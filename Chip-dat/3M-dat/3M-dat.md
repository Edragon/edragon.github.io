### 选型速查（按需求）

| 需求 | 选它 |
| :--- | :--- |
| 船体接缝永久密封（不拆） | **5200 慢干**（295ml 大支划算） |
| 设备舱盖/需检修处 | **4000UV**（能拆开检修） |
| 透明件/窗户 | **PN8029 / PN8019** |
| 赶工期快速定型 | **5200 快干** |
| 黑色外观/遮光 | **4000UV 黑** |

5200   = 粘死（永久，船级最强）
4000UV = 粘住但能拆（可维修，抗UV）
PN     = 通用透明（非船级）


## 5200 

一、5200 系列（永久粘接）

定位：高强度永久粘接——粘上就拆不下来了（除非暴力破坏）

类型
• 说明: 聚氨酯密封胶

强度
• 说明: ⭐️⭐️⭐️ 最高（船级）

耐水性
• 说明: 水下/水线上都能用

耐UV
• 说明: 好

固化
• 说明: 快干 / 慢干 两种（见下）

可拆卸
• 说明: ❌ 永久粘接（拆除会损坏基材）

适用
• 说明: 船体结构粘接、永久密封、加固

快干 vs 慢干区别：
**快干**
• 表干时间: 1-2 小时
• 适用: 需要快速定型、赶工期

**慢干**
• 表干时间: 4-8 小时
• 适用: 需要时间调整位置、大面积施工

注意：5200 一旦粘上基本"焊死"，拆修会破坏材料——用在不打算拆的地方。


## 4000UV 

定位：中等强度 + 可拆卸 + 抗UV

类型
• 说明: 聚氨酯密封胶

强度
• 说明: 中等（比 5200 低）

抗UV
• 说明: ✅ 主打卖点（耐晒不老化）

可拆卸
• 说明: ✅ 可以拆（用工具剥离）

适用
• 说明: 甲板以上、需要以后检修的接缝、外部装饰

5200 vs 4000UV 一句话：
5200   = 粘死（永久）
4000UV = 粘住但能拆（可维修）


## PN8029透明 / PN8019透明

PN 系列是 3M 通用密封胶（非船用专用）：

**PN8029**
• 特点: 透明、大支 304ml、通用密封（门窗/接缝）

**PN8019**
• 特点: 透明、小支 88ml、通用密封

用途：透明密封、防水、填缝——普通家居/电子密封，非船级。
