


# VL211-dat

- [[VIA-dat]] - [[USB-hub-dat]] - [[VL211-dat]]

The VIA Labs VL211 is a 4-port USB 3.1 Gen 1 (5Gbps) hub controller manufactured by VIA Labs, Inc. (VLI).

Key Specifications & Features

- • Configuration: 4 Downstream Facing Ports (DFP)—one USB 3.1 SuperSpeed (5Gbps) port and three USB 2.0 High-Speed/Full-Speed/Low-Speed ports.
- • Architecture: USB 2.0 Hub with Multiple Transaction Translators (MTT) for improved multi-device performance.
- • Power & Charging: Built-in USB Battery Charging v1.2 support (supporting SDP, CDP, DCP, Apple 2.4A, Samsung, and YD/T 1591-2009), plus integrated 5V to 1.1V DC-DC switching and 5V to 3.3V LDO regulators.
- • Virtual Devices & Control: Optional USB HID and Billboard 1.1 virtual devices, with an SPI interface allowing firmware upgrades over USB.
- • Package: 48-pin QFN package (6 x 6 x 0.85 mm).
