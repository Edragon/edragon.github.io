

# VL103-dat



- [[VIA-dat]] - [[USB-hub-dat]] - [[VL211-dat]] - [[VL103-dat]] - [[displayport-dat]] - [[usb-SDK-dat]] - [[USB-PD-dat]]


The VIA Labs VL103 is a single-chip DisplayPort Alt-mode and Power Delivery (PD) controller designed for USB-C video adapters, multi-function docking stations, and USB-to-DisplayPort converters.

Key Features

- • DisplayPort Alt-Mode & Video: Enables video output transmission over USB-C connections.
- • Power Delivery (PD): Supports USB Power Delivery (certified for PD 2.0, PD 3.0, and PD 3.2), including integrated UFP/DRP charging up to 100W (SPR power rules), dead battery mode, and Fast Role Swap (FRS).
- • Integrated Functions: Features an 80C32 MCU, USB Billboard device function/class support, smart auto-standby, SBU1/SBU2 switches, D+/D- charging ePHY, and built-in LDO regulators (5V-to-3.3V/1.8V).
- • Packages & Variants:
	• VL103-Q4 / QFN-48: QFN 48-lead package (6 x 6 x 0.85 mm).
	• VL103-Q3 / QFN-32: QFN 32-lead package (5 x 5 x 0.85 mm).
