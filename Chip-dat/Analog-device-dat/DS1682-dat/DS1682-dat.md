

# DS1682-dat

The DS1682 is an integrated elapsed-time recorder containing a factory-calibrated, temperature-compensated RC time base that eliminates the need for an external crystal. Using EEPROM technology to maintain data in the absence of power, the DS1682 requires no backup power source. 

The DS1682 detects and records the number of events on the EVENT pin and the total cumulative event time since the DS1682 was last reset to 0. 

The ALARM pin alerts the user when the total time accumulated equals the user-programmed alarm value. 

The polarity of the open-drain ALARM pin can be programmed to either drive low or to become high impedance upon an alarm condition. 

The DS1682 is ideal for applications that monitor the total amount of time that a device has been in operation and/or the number of uses since inception of service, repair, or the last calibration.
