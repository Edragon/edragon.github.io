## MHCW05P-IB


`MHCW05P-IB` is a 2.4 GHz Wi-Fi IoT module made by Xiaomi, built on the MediaTek MT7682 chipset with **an external antenna connector (-IB variant)** for smart home appliances and industrial automation.

Key Specifications

- • Manufacturer. Xiaomi Communications
- • Chipset. MediaTek MT7682
- • Wireless Standard. 2.4 GHz Wi-Fi (2400–2483.5 MHz)
- • Antenna. External antenna interface (whereas the MHCW05P-B variant uses an onboard PCB antenna)
- • CMIIT ID. 2019DP2317(M)
- • Supported Features. Password sync and automatic OTA firmware updates (requires Xiaomi IoT SDK v2.1.3 or higher); does not support one-click fast connect or WPA3.
