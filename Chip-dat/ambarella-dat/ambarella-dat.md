The Ambarella `H22N-A0-HR` (often designated in datasheets as part of the H22/H22N family) is a low-power, 14nm Ultra HD System-on-Chip (SoC) manufactured by Ambarella. It is primarily designed for high-resolution edge video devices such as action cameras (e.g., Insta360 GO 3), police body-worn cameras, and commercial drones.
The "N" variant specific to the H22N line denotes hardware integration built to support LPDDR4 memory up to a 1 GHz clock rate.

Key Specifications

• Processor Core: Quad-core Arm Cortex-A53 CPU running up to 1.2 GHz / 1 GHz. It handles flight control, basic computer vision (like on-board face recognition), and dual operating systems (Linux and ThreadX).
• Memory Support: Dedicated LPDDR4 configuration with a 32-bit data bus and up to 2 GB capacity.
• Video Encoding: High-efficiency 4Kp60 video encoding using both H.265/HEVC and H.264/AVC codecs.
• Image Processing & Logic: Supports multi-exposure High Dynamic Range (HDR) up to 4Kp30 and 3D electronic image stabilization (EIS) with 6-axis correction.
• Manufacturing Process: Built on a highly efficient 14nm CMOS process technology optimized for extended battery life and low thermal output in compact enclosures.
