


# renesas-memory-dat

- [[SRAM-dat]] - [[renesas-dat]] - [[renesas-memory-dat]]



The `71256L35TDB` is an obsolete 256 Kbit (32K x 8) asynchronous CMOS Static RAM (SRAM) integrated circuit manufactured by Renesas in a 28-pin ceramic DIP (CDIP-28) package.

Key Specifications

• Memory Size & Organization: 256 Kbit (32K x 8-bit)
• Memory Type: Volatile, asynchronous SRAM with a parallel interface
• Access / Write Cycle Time: 35 ns
• Supply Voltage: 4.5V to 5.5V (nominal 5.0V)
• Low-Power Features: Standby mode when chip select (CS) is high, and battery backup data retention on the low-power (L) variant
• Operating Temperature: -55°C to +125°C
• Package & Mounting: 28-CDIP (0.300 in / 7.62 mm width), through-hole
