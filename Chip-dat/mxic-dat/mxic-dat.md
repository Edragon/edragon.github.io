


# mxic-dat

- [[flash-nor-dat]] - [[mxic-dat]] - [[25x128-dat]]


The `25L12835F` (typically the `Macronix` `MX25L12835F`) is a 3V, 128M-bit (16MB) Serial NOR Flash memory integrated circuit supporting Single, Dual, and Quad I/O (SPI/QPI) protocols.

Key Specifications

• Capacity & Organization: 128 Mbit (16 MB); configured as 16,777,216 × 8 bits internally (or x1, x2, x4 in Multi-I/O modes).
• Supply Voltage: 2.7V to 3.6V single power supply.
• Interface & Speed: Serial Peripheral Interface (SPI Mode 0 and Mode 3), Dual I/O, Quad I/O, and QPI up to 133 MHz (varies by variant/grade).
• Sector/Block Architecture: 256-byte page buffer; 4 KB sectors, 32 KB blocks, and 64 KB blocks.
• Endurance & Retention: 100,000 program/erase cycles and 20-year data retention.
• Security & Features: 4K-bit secured OTP area, block lock/sector protection, deep power-down mode, and fast read/boot modes.
• Common Packages: Surface-mount packages such as 8-pin SOIC/SOP (e.g., MX25L12835FM2I-10G) and 16-pin SOP (e.g., MX25L12835FMI-10G).
