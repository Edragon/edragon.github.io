


# LP3987-dat


The LP3987H is a 600mA ultra-low noise, ultra-fast CMOS low-dropout (LDO) linear voltage regulator manufactured by Lowpower Semiconductor (Lowpower Semi).

Key Specifications & Features

- Manufacturer: Lowpower Semiconductor Inc.
- Output Current: 600 mA
- Input Voltage Range: 2.5V to 6.0V
- Available Fixed Output Voltages: 1.2V, 1.5V, 1.8V, 2.5V, 2.8V, 3.0V, 3.3V (e.g., LP3987H-33B5F for 3.3V, LP3987H-18B5F for 1.8V)
- Package Type: 5-lead SOT-23-5
- Quiescent Current (\(I_{q}\)): ~90 µA to 130 µA
- Shutdown Current: < 0.01 μA
- Turn-on Time: < 20 μs
- PSRR (Power Supply Rejection Ratio): Approx. 65 dB to 65 dB @ 1 kHz
- Dropout Voltage: ~360 mV @ 600 mA
- Operating Junction Temperature: -40°C to +125°C
- Protections: Over-current protection, thermal shutdown, and enable control / output discharge
