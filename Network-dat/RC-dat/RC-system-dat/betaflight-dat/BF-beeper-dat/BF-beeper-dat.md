

# BF-beeper-dat

DShot Beacon（电机鸣叫，0g）

- [[Betaflight-configuration-dat]] - [[BF-beeper-dat]]


Go to the **CLI** tab at the bottom of the left menu.

Type `beeper` and press Enter to see which sources are enabled or disabled.

To make sure manual switch beeping and lost-model warnings are fully enabled, type the following commands:

    beeper ON
    set bsave
