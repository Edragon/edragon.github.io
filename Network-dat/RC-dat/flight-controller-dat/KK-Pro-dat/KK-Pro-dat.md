


# KK-Pro-dat

• 传感器：3 轴陀螺仪 + 3 轴加速度计（支持自稳）
  ⚠️ 无气压计 / 无 GPS / 无磁罗盘
• 输出：PWM
• 接收机兼容：PCM + 2.4G 数字接收机（通用性强 ✅）

• 供电：5V
