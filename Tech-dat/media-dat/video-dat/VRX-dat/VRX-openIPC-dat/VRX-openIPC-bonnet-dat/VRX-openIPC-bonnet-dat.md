


# VRX-openIPC-bonnet-dat

- [[VRX-dat]] - [[VRX-openIPC-bonnet-dat]] - [[openIPC-dat]]

- 宽压输入 2S-6S（双向 BEC）+ 5V/3.3V 输出 + 电池电压监测
- 4 口 USB 2.0 Hub
- ⭐️ 双 RTL8812AU WiFi 模块 + 4× FEM（前端放大）→ 距离/带宽增强
- ⭐️ HDMI → DisplayPort 桥（接低延迟外接屏/眼镜）
- 5 向摇杆 + 按键（UI/OSD 交互）
- 6 轴 IMU
- UART + I2C 扩展口


典型用途：
1. ⭐️ 便携 VRX 地面站（SBC + Bonnet）
2. 远航中继节点（防水壳）
3. 一体化 FPV 遥控器（HDMI + ELRS + 屏）
4. ⭐️ 眼镜式 VRX（配 Meta Quest 3）


no need SBC 

    ⭐️ Bonnet 可以【不需要 SBC】，直接用 Android 手机 / Meta Quest 3
    （官方文档明确：接 SBC 那步对手机/Quest 是 optional）
            ↓
    ⭐️ 即：Bonnet + 你的 Pixel 手机 = 一个完整地面站
    （这正好回答了你上一个问题！）

极简方案

    OpenIPC Bonnet + 你的 Pixel 手机
            ↓
    手机 App 显示（⭐️ 完全不需要 SBC！）
    ⭐️ 最省钱、最快验证
