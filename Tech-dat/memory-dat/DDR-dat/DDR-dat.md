


# DDR-dat

- [[PCB-design-complex-dat]] - [[DDR-dat]] - [[MIPI-dat]]



- DDR 走线是第二大技术门槛：等长、阻抗、参考平面完整、无跨分割
- 强烈建议基于海思官方参考设计（DMEB 开发板原理图）改 —— 自己从零布 DDR，失败率极高
- 去耦电容：BGA 底部要放，空间不够时经常要上 0201
- 传感器模拟电源要干净：LDO + LC 滤波，绝不能用普通 DCDC 直供 AVDD（会引入条纹噪声）
- 时钟（传感器 74.25MHz / 37.125MHz 输入）：包地处理
- 传感器板建议独立 4 层，MIPI 差分 + 干净电源 + 地平面
