

# antenna-diversity-dat

真分集（True Diversity） = 眼镜里两路独立接收模块，各接一根天线，系统实时选信号更强的那路。




层级                          机制                        弱信号时表现
① 天线分集 Antenna Diversity   切两根天线选强的              ❌ 切换瞬间闪断/黑屏
② 真分集 True Diversity        两台独立接收机持续比较合并     ✅ 平滑
③ ② + 同步脉冲重建              SteadyView / RapidFire / Fusion  ⭐️ 弱信号也不滚动撕裂
   （Skyzone / ImmersionRC / TBS 的招牌技术）
        ↓
⭐️ 你要的是 ③，至少也要 ②
   便宜的 4.3"/5" box 眼镜大多停在 ①，甚至只是"A/B 切换开关"





近距离（<200m）：
   余量有 28-54dB，天线增益那几 dB 完全无关紧要
   ⭐️ 决定成败的是【有没有死角 + 极化对不对 + 有没有被挡】

远距离（>1km）：
   余量掉到 8-14dB，这时增益才真正开始起作用
        ↓
⭐️ 所以正确用法是"按距离选天线"：
   贴身/绕圈 → 低 dB 全向（2-3dBi）
   直线远航 → 高 dB 定向（11-20dBi）
   而不是"一根高增益打天下"




只算分集增益，其他一律不动

---

一、增益从哪来（一句话）

2.4G 与 900M 的多径衰落【不相关】
        ↓
单链路：撞上衰落零点 → 中断
双链路：两条同时撞零点的概率 = 单链路的【平方】
        ↓
达到同样可靠性所需的裕量 → 减半


---

二、分集增益理论值（2 支路选择合并）

目标中断概率    单链路需留裕量    双支路需留裕量    分集增益
   10%            10 dB            5 dB          +5 dB
   ⭐ 1%          20 dB           10 dB         +10 dB
   0.1%           30 dB           15 dB         +15 dB


---

三、换成距离（你的基础：120m 高度，40log 区）

若频段保持 2.4G 1W（基准 35.7 km）
+5 dB  → 47.6 km   ×1.33  (+33%)
+10 dB → 63.4 km   ×1.78  (+78%)   ⭐ 1% 中断口径
+15 dB → 84.6 km   ×2.37  (+137%)


若频段是 900M 1W（基准 47.6 km）
+5 dB  → 63.4 km   ×1.33
+10 dB → 84.6 km   ×1.78
+15 dB → 112.8 km  ×2.37

---

五、⚠️ 唯一必须保留的前提（否则这个数字会虚高）

分集增益【只在有衰落时存在】

· 理论值（Rayleigh 深衰落模型）  : +10 dB @1% 中断
· 开阔高空 LOS（轻衰落）实际兑现  : ⭐ 约 +4 ~ +8 dB
· 完全干净的自由空间（无多径）    : 接近 0 dB（没什么可救的）
        ↓
⭐ 工程上取 +5 ~ +8 dB 更靠谱
   → 对应距离 ×1.33 ~ ×1.58（你这个 120m/40log 场景）
   而不是 ×1.78


---

📋 一句话结论

纯分集收益 = 等效 +5 ~ +10 dB 链路预算（取决于你要多可靠）
        ↓
换成距离：
    乐观口径（+10dB，深衰落环境）  → ×1.78
    现实口径（+5~8dB，开阔环境）   → ×1.33 ~ ×1.58
        ↓
⭐ 以你现有基础（2.4G 1W 理论 35.7 km）：
   只加分集 → 理论 47-63 km，实际环境再打 5-7 折 ≈ 28-40 km
   （这个收益是"抗中断"性质，不是"多飞多远"性质）
