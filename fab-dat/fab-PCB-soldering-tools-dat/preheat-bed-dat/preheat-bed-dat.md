- desoldering temperature 270 degree C


## manual workflow 

1. 台面清干净、平整（铝板/铜板；可垫高温纸/铝箔防助焊剂污染）
2. 板子完全贴平台面（不平 = 局部不融 → 这是最常见的失败原因）
3. 板边用高温胶带/夹具固定（防移位，但别压元件）
4. 观察锡膏变化，不要用时间盲猜：
   - 灰白哑光 → 变亮、湿润、塌陷 → 元件自动对正（self-alignment）
5. 全部锡变亮后，再保持 20-30 秒（让大热容焊点彻底融透）
6. 快速取下冷却（移到金属台/大理石/吹风）— 冷却 ≤4°C/s，别在台上慢慢凉
7. 台面停留过久 = 氧化、烧板、元件损伤
