堆叠装配（结构风险）

- BTB 连接器：对位精度、压合、虚接是主要失效模式
- 焊接式堆叠：共面度（coplanarity）要求高，需要治具保证
- 堆叠后无法单独测试 → 必须做分板测试 + 合体测试两道
- 结构固定（螺丝/卡扣/背胶）：振动下连接器会松 → 需要加固 + 防松设计
