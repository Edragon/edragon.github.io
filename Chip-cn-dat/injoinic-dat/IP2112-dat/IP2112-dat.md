



# IP2112-dat

- [[IP2112-dat]] - `A12K` - [[fast-charge-protocols-dat]] - [[IP5568-dat]]

The SMD top-marking code A12 (or A12K) on a SOT-23-6 package typically corresponds to the Injoinic IP2112 (or IP2112A).

Component Overview: Injoinic IP2112 / IP2112A

• Manufacturer: Injoinic (英集芯)
• Package: SOT-23-6
• Function: Dedicated USB Port Charging Protocol / Identification IC (supports dual-channel or single-channel USB port charging control).
• Key Features:
	• Supported Charging Protocols: Apple 2.0A/1.0A, Samsung 2.0A, and USB BC1.2 (automatic detection and protocol switching).
	• Operating Voltage: 3.0V to 5.5V
	• Max Charge Current: Up to 2A
	• Quiescent Current (\(I_{q}\)): Very low, typically ~66 µA
	• Operating Temperature: -40°C to +85°C
