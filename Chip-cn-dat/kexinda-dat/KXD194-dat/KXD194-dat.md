



# KXD194-dat

- [[kexinda-dat]] - [[KXD194-dat]] - [[infrared-dat]] 


The KXD194 (produced by Shenzhen Kexinda Electronics Co., Ltd.) is an MTP infrared remote control transmitter IC designed for low-power remote applications.

Key Specifications

- • Type: MTP Infrared Remote Control Transmitter IC (supports secondary/multi-time programming)
- • Operating Voltage: 1.8V to 3.6V (functional down to 1.3V)
- • Key/Pin Support:
    - • `SOP12` package supports up to 63 keys
    - • `SOP8` package supports up to 25 keys
- • Oscillator & Frequency: Built-in high-precision oscillator at 37.92 kHz (frequency accuracy ±1.5%)
- • Current Consumption:
    - • Static current: 1 µA
    - • Operating current: 0.5 mA
- • Protection & Features: Built-in watchdog timer, 4 kV ESD protection, and configurable pins (indicator LED high/low active, format switch/SHIFT, or floating).
- • Operating Temperature: -20°C to +70°C
