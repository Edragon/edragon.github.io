


# A-power-dat

- [[mosfet-dat]] - [[A-power-dat]] - [[AP135N03-dat]]

The `AP135N03` (specifically part number AP135N03NF) is a 30V N-Channel Enhancement Mode MOSFET electronic component. It is manufactured by A-Power Microelectronics (also known as APME).

Key Technical Specifications

• Component Type: N-Channel Enhancement Mode MOSFET
• Drain-Source Voltage (\(V_{DS}\)): 30V
• Continuous Drain Current (\(I_{D}\)): 135A
• Package Type: DFN5X6-8L (also listed as PDFN56-8L or PDFN5X6-8L), which is a surface-mount package featuring 8 leads.
