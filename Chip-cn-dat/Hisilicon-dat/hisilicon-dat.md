## info 


- Hi3516 的 SDK 需要 NDA + 正式代理渠道。电商散片/拆机片可能拿不到 SDK 和完整文档 → 项目直接停摆
- 安防芯片经历过 2020-21 年爆炒缺货期，市场上翻新片/散新片/拆机片很多（尤其 Hi3516DV300 这类热门型号）


动作：
- 走原厂/授权代理渠道，同时把 SDK 授权、参考设计、传感器驱动一起谈
- 收到货做外观 + 丝印 + 批次核验；必要时做 X-Ray/开封检查

Hi3516 型号差异（先确认你要哪个）：
- Hi3516EV300 — 行业专用 3M/5M IP 摄像机 SoC，H.265
- Hi3516CV500 / CV610 — 消费类，CV610 还带 1T NPU（无人机/云台/行车记录仪）
- Hi3516DV300 / DV500 — 智能视觉/机器视觉向
- 型号不同 → DDR 类型（DDR2/DDR3）、封装、外围需求、SDK 版本全都不同
